# Conector Google Drive para Leadtita: contrato (ORQ-1-0146 a 0148)

Decisión del usuario: modo **híbrido** y tabla nueva autorizada.
- Hoy: scope `https://www.googleapis.com/auth/drive.file` (+ `openid email`), sin auditoría de Google, para cualquier usuario. El usuario conecta Google una vez (OAuth offline) y elige archivos con Google Picker; quedan "conectados" y Leadtita los lee cuando quiera (Sheets como tabla, Docs como texto, CSV/PDF/MD vía Drive).
- Preparado: modo "Drive completo" (`drive.readonly`, `spreadsheets.readonly`, `documents.readonly`) detrás de la env `GOOGLE_DRIVE_FULL_ACCESS=true`, que habilita búsqueda en todo el Drive. Apagado por defecto (requiere verificación de Google).
- Reusa el OAuth client existente del login con Google (`GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET`, revisá los nombres reales en .env.example y app/api/auth/google). Picker: `NEXT_PUBLIC_GOOGLE_PICKER_API_KEY` y `NEXT_PUBLIC_GOOGLE_APP_ID` (número del proyecto). Cifrado: `GOOGLE_TOKEN_ENCRYPTION_KEY` (32 bytes base64). Agregar las tres a .env.example vacías.

## Datos: `pb_migrations/1794390000_add_google_connections.js` (0146)
Colección `google_connections` (base), creada con el patrón probado de 1762471200 (fields como objetos planos + reglas/índices en segundo save; ver ORQ-1-0118): `user` (relation users, required, cascadeDelete, único), `google_email` (text), `google_sub` (text), `scopes` (text), `refresh_token_enc` (text, max 4000), `access_token_enc` (text, max 4000), `access_expires_at` (date), `files` (json: `[{ id, name, mimeType, url, addedAt }]`, máx 50), `created`/`updated` autodate. Reglas: list/view/create/update/delete `null` (solo servidor). Índice único `(user)`.

## Servidor
- `lib/server/google-connections.ts` (0146): `encryptToken`/`decryptToken` (AES-256-GCM, iv aleatorio, auth tag), `getConnection(userId)`, `saveConnection(userId, data)`, `deleteConnection(userId)` (revoca en Google: POST https://oauth2.googleapis.com/revoke), `getValidAccessToken(userId)` (refresca con refresh token si venció; si Google responde invalid_grant → borra la conexión y lanza `GoogleNotConnectedError`), `addFiles(userId, files)`, `removeFile(userId, fileId)`, `listFiles(userId)`. Nunca exponer tokens al cliente ni loguearlos.
- `lib/server/google-drive.ts` (0146): `readDriveFile(userId, fileId)` → `{ kind: "table", name, rows, columns } | { kind: "text", name, text }`: Google Sheet → Sheets API values (primera hoja o todas con límite 2.000 filas), Google Doc → export `text/plain`, CSV/MD/TXT → `alt=media`, PDF → `alt=media` + unpdf (ya instalado). Límites de tamaño/tiempo. `searchDriveFiles(userId, query)` solo si `GOOGLE_DRIVE_FULL_ACCESS=true`, si no lista solo los archivos conectados.
- Rutas (0147): `GET /api/integrations/google/connect` (auth leadta obligatoria, `state` firmado anti-CSRF ligado al usuario, `access_type=offline`, `prompt=consent`, `include_granted_scopes=true`, scopes según modo), `GET /api/integrations/google/callback` (valida state, intercambia code, guarda cifrado, redirige a /leadtita?google=connected), `POST /api/integrations/google/disconnect`, `GET /api/integrations/google/status` → `{ connected, email, files, fullAccess }`, `POST /api/integrations/google/files` (agregar ids elegidos en Picker: verificar con Drive API `files.get` que el usuario tiene acceso), `DELETE /api/integrations/google/files/[id]`, `GET /api/integrations/google/picker-token` (access token de corta vida SOLO para abrir el Picker con scope drive.file).
