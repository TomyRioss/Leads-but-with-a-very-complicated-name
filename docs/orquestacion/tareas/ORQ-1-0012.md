## Spec
Problema reportado por el usuario (captura): en `/owner` los estilos no se aplican (topbar apilado sin flex, resumen y usuarios como texto plano). Pedido explícito del usuario: "no uses css, usa tailwindcss". El proyecto ya tiene Tailwind v4 (`@import "tailwindcss"` en `app/globals.css`, `@tailwindcss/turbopack`).

Hacer:
1. Reescribí el estilo de `app/owner/owner-panel.tsx` (y `page.tsx` si hace falta) usando solo clases de utilidad Tailwind v4. Eliminá `app/owner/owner.module.css` y el `import styles`. No agregues CSS nuevo en ningún archivo.
2. Colores: tokens de marca de AGENTS.md vía valores arbitrarios que leen las variables ya definidas en `:root` (p. ej. `bg-(--ash-100)`, `text-(--ink)`, `border-(--line)`, `bg-(--lime)`, `text-(--muted)`, `bg-(--paper)`). No edites `app/globals.css` ni definas `@theme`. Fuente Geist heredada. Revisá la sintaxis de Tailwind v4 (variables con paréntesis `bg-(--x)`) en la documentación oficial si hace falta.
3. Mantené TODO el comportamiento y el contenido actuales (login por rol/redirect, resumen con tarjetas y desglose, tabla con búsqueda/paginación, cards en móvil, drawer con focus trap, confirmaciones, estados vacío/cargando/error, accesibilidad, `sr-only` con la utilidad `sr-only`). Spinner con `animate-spin`; responsive con prefijos `sm:`/`md:`; tabla en móvil como cards usando utilidades (`max-md:`), con `data-label` + pseudo-elementos vía `before:content-[attr(data-label)]`.
4. Diseño sobrio de back-office, layout correcto: topbar con logo + badge Owner a la izquierda y "Salir" a la derecha, contenido en contenedor `max-w-[1160px]` centrado, tarjetas en grilla, tabla con borde redondeado y scroll horizontal contenido.
5. Después de reescribir, verificá que cada `className` use utilidades válidas (sin clases inventadas) y que `grep -rn "styles\." app/owner` y `grep -rn "module.css" app/owner` no devuelvan nada.

Puede editar: solo `app/owner/**`. Otro archivo requiere `ask`.
Restricciones: AGENTS.md y CLAUDE.md del repo; sin commits; REGLA DURA: no ejecutes nada contra PocketBase ni levantes `npm run dev`; sin dependencias nuevas.
Hecho cuando: `/owner` no usa CSS propio, solo Tailwind, con el mismo comportamiento.
Evidencia requerida (headless): `npx tsc --noEmit` y `npm run lint` sin errores; los dos grep anteriores vacíos.
Cierre: `worker_done` con resumen de 4 líneas como máximo.
