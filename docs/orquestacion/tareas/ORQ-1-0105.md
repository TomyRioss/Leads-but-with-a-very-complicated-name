## Spec

Objetivo: blog público simple pero MUY estético, coherente con la landing (revisá app/landing/*.tsx y landing.css para tipografía, ritmo y estilo; paleta y Geist de AGENTS.md). Usá las skills frontend-design / impeccable como guía.
