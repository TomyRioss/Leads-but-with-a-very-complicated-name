Objetivo: el usuario quiere una funcionalidad "Buscar Personas" en leadta para buscar individuos por segmento, p. ej. "Freelancers", "Inició una relación hace poco", "Programadores", "Personas mayores". No sabe cómo funcionaría. 3.
