## Spec
Hoy, en "Mis leads" de /lead-suite (app/[locale]/lead-suite/leads-list.tsx), el botón "Cargar contacto" de cada fila solo precarga un texto en el chat ("Ya le hablé a … por") y obliga a terminarlo y enviarlo al asistente. El usuario quiere que desde la lista NO haga falta el chat.
Objetivo:
1. "Cargar contacto" abre un formulario directo para ese lead (diálogo/drawer accesible con el patrón de diálogos de la app, centrado como el de Comentarios; en móvil a pantalla completa o bottom sheet): canal (whatsapp/email/teléfono/instagram/linkedin/en persona/otro, como segmentado o select con íconos lucide), fecha y hora (default ahora, editable, `<input type="datetime-local">`), estado (contactado por defecto; respondió/reunión/ganado/perdido), mensaje enviado (textarea, opcional) y notas (opcional). Guardar con estados cargando/éxito/error; al guardar, cerrar, actualizar la fila (estado/fecha) y refrescar métricas del dashboard; foco gestionado.
2. API directa `POST /api/lead-suite/contacts` con body `RecordContactInput` del contrato (docs/orquestacion/lead-suite-contrato.md) → `{ contact: LeadContact, lead: LeadMatch }`, usando `recordLeadContact` de lib/server/lead-suite.ts (verifica pertenencia), auth obligatoria, validación (canal/estado válidos, fecha no futura, longitudes), errores con el patrón existente, sin créditos.
3. Quitá el prefill al chat desde la lista (el chat sigue disponible para quien quiera registrar hablando). Si chat-panel.tsx expone el prefill solo para esto, simplificalo.
Paleta y estilo de marca (como el rediseño de ORQ-1-0120), sin SVG a mano, i18n es/en mismas claves.
Puede editar: solo los `archivos` listados. Cualquier otro archivo requiere `ask`.
Restricciones: AGENTS.md y CLAUDE.md del repo, sin commits, sin comandos de base, no tocar la terminal del dev server.
Hecho cuando: desde "Mis leads" se registra un contacto completo sin usar el chat y el dashboard se actualiza.
Evidencia requerida (headless): `npx tsc --noEmit` y `npx eslint "app/[locale]/lead-suite" app/api/lead-suite/contacts` exit 0; una prueba real con la cuenta de prueba de ORQ-1-0107 registrando un contacto en un lead existente (status 200 y la fila cambia a "Contactado"), con captura en docs/qa-mobile/lead-suite-contact-form-{360,1280}.png.
Cierre: `worker_done` con resumen de 5 líneas como máximo.
