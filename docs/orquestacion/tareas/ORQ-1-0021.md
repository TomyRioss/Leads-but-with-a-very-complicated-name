## Spec
Objetivo: un usuario nuevo que entra a /buscar no sabe cómo hacer su primera búsqueda. Agregar un onboarding guiado que lo acompañe paso a paso a buscar UN SOLO lead, y que se pueda omitir en cualquier momento.
1. Se muestra la primera vez que un usuario logueado entra a /buscar (y si no tiene búsquedas previas, si es fácil de saber con la API existente). Persistencia de "completado/omitido" en localStorage, con clave por id de usuario, con try/catch. Sin cambios en la base de datos.
2. Pasos (coachmarks anclados a los controles reales del form, con resaltado y foco): qué es un lead → elegir rubro/búsqueda → elegir ubicación → cantidad fijada en 1 → lanzar búsqueda → dónde ver el resultado en la tabla y qué hacer después (exportar/analizar). Usá los controles reales del form; el usuario los completa él mismo, el tour avanza.
3. Cantidad: hoy `productionBatchSizes` arranca en 5. En el flujo guiado la búsqueda debe ser de 1 lead. Si el backend valida tamaños y rechaza 1, ajustá `app/api/search/route.ts` con el cambio mínimo (y que cobre crédito proporcional como hoy). Fuera del tour no cambies las opciones.
4. "Omitir tutorial" siempre visible, Escape cierra, botones Atrás/Siguiente, contador "Paso n de N", accesible (role dialog, aria, foco gestionado), mobile OK. Opción para relanzarlo (p. ej. un botón "Ver tutorial" discreto en /buscar).
5. Antes de escribir un tour a mano, revisá si conviene una librería mantenida (driver.js, react-joyride, etc.). Si querés agregar una dependencia, pedilo con `ask` justificando licencia/tamaño; si no, componente propio liviano.
